เริ่มใช้

3 ขั้น พร้อมโพสต์

1

โหลด + ติดตั้ง

ดับเบิลคลิกตัวติดตั้ง ระบบลงทุกอย่างให้เอง (Python, เครื่องมือ) แล้วสร้างแอปบนหน้าจอ

2

เปิด + ตั้งค่า

เปิดแอป จะมีหน้าพาตั้งค่า 5 ขั้น: ชื่อร้าน, คีย์ AI, ส่วนเสริม Chrome, เชื่อมมือถือ, แพลตฟอร์ม

3

สร้าง + โพสต์

ดูดสินค้า Shopee → AI สร้างคลิป → มือถือโพสต์ให้เอง หรือเปิดโหมดอัตโนมัติทิ้งไว้

ก่อนเริ่ม

ต้องเตรียม

อินเทอร์เน็ตตอนติดตั้ง (โหลดโค้ด + เครื่องมือ)
มือถือ Android + สาย USBเปิด USB debugging + ลง ADBKeyboard
บัญชี Googleใช้เข้า Google Flow เพื่อสร้างคลิป
Chromeสำหรับส่วนเสริม (ดูดสินค้า + ขับ Flow)

เปิดครั้งแรก (ตัวติดตั้งยังไม่ได้เซ็นใบรับรอง — เป็นเรื่องปกติ)

  • macOS: คลิกขวาที่แอป > Open > Open · ถ้าเป็น macOS 15+ ไม่มีปุ่ม ให้ไป System Settings > Privacy & Security เลื่อนลงล่าง กด Open Anyway
  • Windows: ถ้าขึ้นจอฟ้า SmartScreen กด More info > Run anyway
  • ตัวติดตั้ง ไม่แตะระบบ ลงในโฟลเดอร์ผู้ใช้เอง · ถอนแล้ว ไม่ลบข้อมูลของคุณ
