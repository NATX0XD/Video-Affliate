## เช็กเครื่องพร้อม (ก่อนเริ่มข้อ 1)
ให้ผู้เรียนเปิดเครื่องที่ติดตั้งมาแล้ว แล้วเช็กพร้อมกัน:

1. ดับเบิลคลิก `เปิดโปรแกรม.vbs` → เบราว์เซอร์เด้ง `localhost:3001` เห็นหน้า **ค็อกพิต**
2. เมนู **ตั้งค่า** → มี **Google API key** อยู่แล้ว (ถ้าว่าง ให้ใส่ตอนนี้)
3. เสียบ **แท็บเล็ต Samsung (สาย micro USB)** → เมนู **ดูแลเครื่อง** → กด **สแกน** → เครื่องขึ้นเป็น **ออนไลน์**

> ผู้ติดตั้งควรเตรียมแท็บเล็ตให้พร้อมมาก่อน: USB debugging + ADBKeyboard + Shopee app (login) + ล็อกอิน Google (สำหรับ Flow) — คาบนี้แค่สาธิตการเชื่อม 1 เครื่อง ไม่ต้องตั้งใหม่ทุกคน

**⚠️ ถ้าไม่ผ่าน:** เบราว์เซอร์ไม่เด้ง → `_run-source.bat` ดู error · ไม่เจอเครื่อง → เช็กสาย micro USB + กด Allow บนแท็บเล็ต

## 🔧 ข้อ 1 — ดูดสินค้าเข้าคลัง (Extension)
**(คู่กับสไลด์ #8)** · เป้าหมาย: มีสินค้าเข้าคลัง

**พูดว่า:** "หัวใจของระบบคือวน 4 ขั้น — เริ่มขั้นแรก: ใช้ Extension ดูดของจาก Shopee เข้าคลัง"

**ทำ:**
1. เปิดหน้าสินค้าใน **Shopee Affiliate** (หน้าที่มีลิงก์ affiliate)
2. กดปุ่ม **ดูดสินค้า** จากปลั๊กอิน (ไอคอน/sidepanel) → รอสักครู่
3. กลับมาหน้าเว็บ → เมนู **คลังคลิป** → กด **รีเฟรช** → เช็กว่าสินค้าเข้ามา (ชื่อ/ราคา/รูป/ลิงก์)

**⚠️ จุดที่มักติด:**
- กดดูดแล้วไม่เข้า → กด **F5** หน้า Shopee แล้วกดใหม่ (ปลั๊กอินหลุด context)
- ปลั๊กอินไม่ขึ้น → เช็กว่าโหลด extension ไว้ใน Chrome แล้ว

**เช็กก่อนไปต่อ:** ทุกคนมีสินค้าอย่างน้อย 1 ชิ้นใน **คลังคลิป** ✅

## 🔧 ข้อ 2 — สั่งสร้างคลิป (Extension → Google Flow)
**(คู่กับสไลด์ #14–15)** · เป้าหมาย: สั่งคลิป 1 ตัว + ใช้ช่วงรอไปตั้งค่า Desktop

**พูดว่า:** "มีของแล้ว สั่งทำคลิปผ่าน Google Flow — เลือกแนวคลิป แทรกตัวละคร กดสร้าง แล้วระหว่างรอเราไปตั้งค่า Desktop กัน"

**ทำ:**
1. ที่ **Extension** เลือกสินค้า → กด **สร้างคลิป** → เปิด modal "ตั้งค่าก่อนสร้าง"
2. เลือก **แนวคลิป** + **แทรกตัวละคร** (มีให้เลือกหลายตัว) → กดสร้าง → Extension ขับ **Google Flow (Veo)** สร้างให้ (รอ ~2-5 นาที)
3. **ระหว่างรอ → สลับไป Desktop ตั้งค่า** (คู่กับสไลด์ #15): เมนู **ตั้งค่า** (เวลาโพสต์/จำนวน-วัน/cooldown/เปิด Shopee Video) + เมนู **ดูแลเครื่อง** (เชื่อมแท็บเล็ต)
4. คลิปเสร็จ → เข้า **คลังคลิป** → กดดูคลิปที่ได้ (รีวิวก่อนโพสต์)

**⚠️ จุดที่มักติด:**
- คลิป/แคปชันว่าง → ยังไม่ได้ใส่ **Google API key** / ยังไม่ได้ล็อกอิน Google → เช็ก **ตั้งค่า**
- Flow ช้า/ล่ม → เตรียม **คลิปสำเร็จไว้ 1 ตัวเป็น backup** + อย่ายิงหลายงานพร้อมกัน (ชน ToS ของ Google)
- อยากเร็ว/ฟรี → ใช้ engine **Template** แทน Flow ได้
- อยากปรับสไตล์/พรอมต์คลิป → อยู่ที่ **ส่วนขยาย (Extension)** ไม่ใช่หน้าเว็บ

**เช็กก่อนไปต่อ:** ทุกคนมีคลิปอย่างน้อย 1 ตัวใน **คลังคลิป** ✅

## 🔧 ข้อ 3 — โพสต์ผ่านมือถือจริง (Desktop)
**(คู่กับสไลด์ #19)** · เป้าหมาย: โพสต์คลิป 1 ตัวสำเร็จ + เห็นจอสด

**พูดว่า:** "ขั้นสุดท้าย ระบบจะสั่งมือถือจริงโพสต์ให้ดู — เปิด **จอสด** จะเห็นมันกดเองเลย"

**ทำ:**
1. เช็กเมนู **ดูแลเครื่อง** — มือถือต้อง **ออนไลน์**
2. เปิดใช้แพลตฟอร์ม **Shopee Video** ก่อน (ค่าเริ่มต้นทุกแพลตฟอร์ม "ปิดอยู่" — การ์ดแพลตฟอร์มในค็อกพิต/ตั้งค่า)
3. เลือกคลิปที่รีวิวแล้วใน **คลังคลิป** → สั่ง **โพสต์**
4. เปิดเมนู **จอสด** → ดูมือถือทำงานจริง (เปิดแอป พิมพ์แคปชัน แนบลิงก์)
5. เสร็จแล้วเช็กเมนู **ผลการโพสต์** → สถานะ **สำเร็จ**

**⚠️ จุดที่มักติด:**
- พิมพ์ไทยเป็นตัวประหลาด/ว่าง → ยังไม่ได้ตั้ง **ADBKeyboard** เป็นคีย์บอร์ด active บนมือถือ
- มือถือหลับ/ล็อกจอกลางคัน → ตั้งจอไม่ให้ดับ + ปลดล็อกค้างไว้ตอนสาธิต
- โพสต์ค้าง → เช็ก **ดูแลเครื่อง** ว่ายังออนไลน์ (สายหลุด/หลับ)

**เช็กก่อนจบ:** มีโพสต์ขึ้นสถานะสำเร็จในหน้า **ผลการโพสต์** ✅

## ปิดท้าย — หลังโพสต์เสร็จ ทำอะไรต่อ (สไลด์ #22–26)

**พูดว่า:** "คลิปขึ้นแล้ว ที่เหลือคือดูแลให้ปลอดภัยและทำซ้ำ วันหลังแค่ดับเบิลคลิก `เปิดโปรแกรม.vbs` แล้ววน 4 ขั้น — หรือเปิดโหมดอัตโนมัติทิ้งไว้"

- **เช็กผล:** ดู **ผลการโพสต์** ว่าสำเร็จ + เปิด **จอสด** ดูเครื่องโพสต์จริง
- **กันถูกแบน:** ถ้าเจอ error/ถูกจำกัด → ลดความถี่ / เพิ่ม cooldown (ตรงวัตถุประสงค์ข้อ 3)
- อธิบาย **โหมดอัตโนมัติ**: เปิดทิ้งไว้ระบบวนโพสต์เอง + พักเครื่องเองเมื่อร้อน/แบตต่ำ · อยากคุมเองก่อน → ตั้ง **รีวิว = hold**
- ทำ **ใบทดสอบ + ใบสั่งงาน** → วางแผน batch สินค้าใหม่
- ชี้ **update.bat** = อัปเดตในอนาคต · ให้ทุกคนแปะ **ภาพโพสต์ที่ทำเสร็จลง Padlet** + เปิด Q&A
