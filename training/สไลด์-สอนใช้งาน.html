Desktop · งาน

คิวงานที่ระบบกำลังทำ

  • แท็บสถานะ ทั้งหมด · รอเผยแพร่ · กำลังทำ · สำเร็จ · พลาด
  • ค้นหา + เรียงลำดับ หาชื่อสินค้า / เรียงใหม่สุด
  • คลิปที่ Extension สร้างเสร็จจะมาโผล่ที่นี่
  • เห็นงานค้าง/พลาด จากตัวเลขแท็บทันที
Desktop · ดูแลเครื่อง

จัดการมือถือที่ใช้โพสต์

  • สแกน ต่อแท็บเล็ต Samsung (สาย micro USB) แล้วกดสแกน เครื่องจะขึ้นมา
  • เชื่อม Wi-Fi ADB ต่อมือถือแบบไร้สายผ่าน IP ได้ด้วย
  • ออนไลน์ / ออฟไลน์ ต้องเป็นออนไลน์ก่อนถึงโพสต์ได้
  • ยังว่าง = ยังไม่พบเครื่อง เช็กสาย + กด Allow บนมือถือ
Desktop · จอสด (ฟาร์มมือถือ)

ดูจอมือถือสด ๆ ทุกเครื่องพร้อมกัน

  • รองรับหลายเครื่อง ดูได้ถึง 20 ช่อง (ฟาร์มมือถือ)
  • การ์ดสถานะ ออนไลน์ · กำลังโพสต์ · พักเครื่อง · อุณหภูมิเฉลี่ย
  • คลิกช่อง เพื่อเข้าไปคุมเครื่องนั้นโดยตรง
  • ใช้ดูตอนระบบโพสต์จริง เห็นมันกดเอง
ลงมือทำ 3

โพสต์ผ่านมือถือจริง

  • เช็กเมนู ดูแลเครื่อง ว่าเจอมือถือ (ออนไลน์)
  • เปิดใช้แพลตฟอร์ม Shopee Video ก่อน (ค่าเริ่มต้นปิดอยู่)
  • เลือกคลิปที่รีวิวแล้วใน คลังคลิป แล้วสั่งโพสต์
  • เปิดเมนู จอสด ดูมือถือทำงานจริง แล้วเช็กผลที่ ผลการโพสต์

Desktop · ผลการโพสต์

ประวัติการโพสต์ทั้งหมด

  • เช็กว่าโพสต์สำเร็จไหม ทุกครั้งที่ระบบโพสต์จะมาบันทึกที่นี่
  • สถานะ สำเร็จ / ไม่สำเร็จ ไล่ดูย้อนหลังได้
  • ระบบยืนยันผลด้วย Gemini Vision (เช็กว่าโพสต์ขึ้นจริง)
  • ใช้เป็นหลักฐานงานที่ทำไปในแต่ละวัน
Desktop · ตั้งค่า

ศูนย์รวมการตั้งค่าทั้งหมด

  • ข้อมูลร้าน ชื่อร้าน/แบรนด์ ใช้เป็นบล็อกในแคปชัน
  • Google API Key (Gemini) ขอฟรีที่ aistudio.google.com/apikey วางแล้วบันทึก
  • แพลตฟอร์มที่โพสต์ เลือกปลายทางแต่ละคลิป
  • หมายเหตุ สไตล์/พรอมต์คลิป อยู่ที่ Extension ไม่ใช่หน้านี้
