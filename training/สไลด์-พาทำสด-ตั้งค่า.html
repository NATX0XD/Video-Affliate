โปรแกรม VDO Gen Auto Pilot มาแก้ตรงนี้ — เก็บคลิป + ทยอยโพสต์ให้อัตโนมัติ
1

หา icon โปรแกรมบนหน้า Desktop

ดับเบิลคลิกเปิด
[ วางภาพ icon โปรแกรม ที่นี่ ]
ใช้ภาพ icon ของคุณ — ให้ทุกคนหาบนหน้าจอ Desktop แล้วดับเบิลคลิกเข้าไป
ไม่เห็น icon / ไม่มี = ยกมือ เดี๋ยวมีผู้ช่วยเดินไปดู
2

ใส่ชื่อร้าน แล้วกดเริ่มใช้งาน

หน้าแรก
พิมพ์ชื่อร้าน/แบรนด์ (หรือชื่อเรา) — ชื่อนี้จะไปโผล่ตอนโพสต์ · จอไม่เหมือน = ยกมือ
3

หน้า Dashboard — จำ 3 เมนูสำคัญ

เมนูซ้าย
ตั้งค่า · คลังคลิป · ผลการโพสต์ — วันนี้เริ่มที่ ตั้งค่า ก่อน
4

เข้าเมนู ตั้งค่า → หัวข้อ AI (Gemini)

ต้องใส่ API Key
ช่องนี้ต้องใส่ Google API Key — ไปเอามาจาก Google AI Studio (หน้าถัดไป)
5

เปิด aistudio.google.com/apikey แล้ว login

Google AI Studio
[ วางภาพ Google AI Studio (หน้า API Keys) ]
พิมพ์ google ai studio → คลิก API Keys → login อีเมลส่วนตัว
ไม่ได้หน้านี้ = ยกมือ เรียกผู้ช่วย
6

กดปุ่มคัดลอก Key

คัดลอก
[ วางภาพ ปุ่มคัดลอก key ]
กดปุ่ม คัดลอก ข้าง key — เราจะเอาไปวางในโปรแกรม
คัดลอกแล้วอย่าเพิ่งปิดหน้า
7

วาง Key ในช่อง AI (Gemini)

กลับมาที่ ตั้งค่า
คลิกช่อง Google API Key → วาง (Ctrl+V) · จอไม่เหมือน = ยกมือ
8

เลื่อนลง เปิดสวิตช์ Shopee

แพลตฟอร์มที่โพสต์
กดสวิตช์ Shopee Video ให้เป็น "เปิด"
9

ออกแบบแคปชัน (จัดลำดับบล็อก)

แคปชัน
ลากบล็อก ชื่อสินค้า · ราคา · ค่าคอม% · ลิงก์ · ชื่อร้าน จัดว่าจะให้อะไรขึ้นก่อน · ดูตัวอย่างด้านล่าง
10

กดบันทึกการตั้งค่า

เสร็จหมวดตั้งค่า
ทุกครั้งที่แก้ตั้งค่า อย่าลืม บันทึกการตั้งค่า
11

ไปเมนู คลังคลิป

คลิปอยู่ที่นี่
คลิปที่ทำมาจะอยู่ที่นี่ · กดแท็บ พร้อมโพสต์ เพื่อดูคลิปที่พร้อม แล้วกดดูตัวอย่าง
ขั้นต่อไป

เลือกคลิป → สั่งโพสต์ → เช็กผล

เมื่อคลังคลิปพร้อมและตั้งค่าเรียบร้อย ต่อไปคือเลือกคลิปสั่งโพสต์ผ่านมือถือจริง แล้วไปดูผลที่ ผลการโพสต์ (หน้าถัดไป)

12

ผลการโพสต์ — เช็กว่าสำเร็จ

ตรวจผล
ทุกครั้งที่ระบบโพสต์ จะมาบันทึกที่นี่ พร้อมสถานะ สำเร็จ/ไม่สำเร็จ
สรุป

ตั้งค่าเสร็จแล้ว
ที่เหลือคือ โพสต์ + ทำซ้ำ
